# 单角色设定与送审模板

版本：P25-CHARACTER-BRIEF/0.1.0。接收：P26；设定事实来自 P04，审美来自 P25，许可范围由 P37 独审。

**本文件尚未填写角色身份，不能当作已批准的人设。** 当前包中的几何指南与空白分层模板仅用于开画，不是角色样本。

## 身份与范围

| 字段 | 本轮填写值 | 由谁确认 |
| --- | --- | --- |
| character_id / 角色名 | 未收到 P04/P22 绑定原件，留空 | P04/P22 |
| 原型版本与 SHA-256 | 待补 | P04 |
| 职业/性格/服装身份 | 待补原型；不从历史 UI 占位猜测 | P04 |
| 年龄设定、发色、瞳色 | 待设定；本规范不推断 | P04/P26 |
| 主要识别物 | 写一个，并说明与设定的联系 | P26，P25 复审 |
| 本次交付范围 | 单一角色质量样本；不默认批量三人 | P01/P25 |
| 目标风格版本 | P25-ART-BIBLE/0.1.0 | P25 |

## 画面决定

填写正面/三分之二朝向、视线目标、左右手动作、主体光源、三种主要材质与主要剪影。武器或道具需说明握持点、受力方向、前后遮挡；没有道具可填 NOT_APPLICABLE 并解释，不为凑清单新增装备。

记录主色、辅色和点缀色的 HEX 值及面积意图。肤色和服装颜色不等同 UI 语义色。给出一张头部局部和一张手/袖口/道具局部，与完整源使用同一版本。

## 必须随样本交回的实体

1. 已填写本设定表，绑定 P04 原型版本；原生分层源及原软件版本。
2. `layers.json` 层树、隐藏层说明与打开/修改/重导出记录；互通 ORA 可选。
3. 1024×1536 透明立绘、512×512 头像、768×1024 半身审查图；横向裁切按 P23 W14/W08 制作，若因识别物不能适配，提交具体反例并标 BLOCKED。
4. 深/浅/棋盘背景的边缘审查图、64/128 像素头像审查图和实际 62×76 小窗辨识图（小窗只在该角色/敌人有用途时提供）。
5. `sample_submission_template.json` 填入真实路径、字节、SHA-256、输入来源、软件、alpha/色彩信息和状态；原版模板中的 null 不能变成虚构值。
6. 实际使用的外部素材、字体、生成工具/编辑过程、来源记录和许可材料，供 P37 独立判断；未用外部素材也记录实际过程。

## 自检记录

逐条填 `sample_acceptance.tsv` 对应条目的证据定位；画师自检与 P25 结果分栏，不替 P25/P37/P30/P35 签字。未收到源或未执行打开操作时不得填写“分层通过”。修订提交时保留旧 base SHA，描述改了哪处、复查了哪些派生裁切。

## 允许的例外

可用高于基准的母版尺寸，但仍交指定审查尺寸和等比关系。姿势透视导致比例偏离时给正面结构辅助，不靠拉伸导出来满足量尺。无法适配当前 UI 窗口时先提交无拉伸的反例，窗口修改交 P23，原稿修改交 P26；不得覆盖他方文件。
