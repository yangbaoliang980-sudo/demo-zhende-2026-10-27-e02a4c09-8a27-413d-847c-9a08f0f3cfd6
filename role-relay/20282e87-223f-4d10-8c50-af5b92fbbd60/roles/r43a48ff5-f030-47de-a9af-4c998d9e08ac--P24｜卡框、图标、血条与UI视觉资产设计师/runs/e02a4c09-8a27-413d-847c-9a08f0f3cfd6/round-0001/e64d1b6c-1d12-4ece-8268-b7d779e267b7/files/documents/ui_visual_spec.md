# P24 UI 视觉规范

版本：P24-UI-VISUAL/0.1.0-placeholder；任务：P24-S03-UI-ASSET-001。

## 1. 本版定位与来源

本包是 S03 必要占位视觉的实体交付。105 个组件源 SVG 与 210 张 RGBA PNG 可供 P19/P20/P28/P30 审查和隔离验证。所有资产标记 PLACEHOLDER / production_allowed=false。P25 的统一 Art Bible 未收到，S08 正式视觉仍为 BLOCKED。

P23 最终 W02/W10 是两张样例的几何和文案基准；保留锚点、各区坐标、文本内容和确认流程。W01_before_review 是上游修正前证据，未作为尺寸基线。P20 的墨紫与淡金色系仅作历史视觉参考，P19 浅色样例不代表已冻结主题。本包的微观样式等待 P25 复核。

## 3. 组件与状态

主要/次要/导航按钮、手牌/敌方框各有 default、hover、pressed、disabled、selected、error。费用徽章也提供上述六态及 unknown；它是父控件内部装饰，不能凭徽章颜色独立表达选择、可支付或错误。

按下态下缘增加横线；选中态用勾号或双框；禁用态使用虚线/斜杠并由 P19/P20 持续显示原因；错误态保留错误标记和原因。unknown/pending 使用独立面板与问号/沙漏，不当成已成功。卡背、填充条、只读图标不拥有悬停和提交行为，矩阵中逐项注明 NOT_APPLICABLE。

焦点是独立 overlay，可与选中或禁用原因详情叠加。禁用业务动作本身是否可聚焦仍遵从 P23/P19/P20；素材不改变 hit area、焦点链或任何命令合法性。六态切图不是六个新业务状态枚举。

24 个图标是本轮从几何路径新绘的图形，没有挪用角色/怪物立绘或外部图标包。所有图标有 default/disabled 两个视觉版本。仍需文字标签；连接可用、记录收到、隔离、奖励到账各自表达。

| 生命/护盾填充 | 304×6 | 从左裁切；0 不画；不按比例缩放笔画 |

| 状态图标 | 32×32 | 2× 为64×64；不是点击区域，交互目标由P23保持至少44×44候选值 |

所有尺寸均为本包候选逻辑像素；P23 的整张设计画板为1280×856，实际界面区为(0,48,1280,720)，上方/下方是审查标注，不得作为游戏HUD内容导入。390px截图只属于上游压力证据，不批准移动端。

卡框文本通用内缩14px；selected/disabled/error 右下 (W-32,H-32,26,26) 是状态标记保留区。按钮对应右上保留区为(W-28,8,18,16)。保留区从文本安全区排除；长文本换行/扩容遵从P23，不得侵占标记或缩小关键字。

2× 的画布、安全区、边界都乘2，归一化 pivot 保持(0.5,0.5)。描述中的边界顺序固定为 left,top,right,bottom。P30 负责转换到实际引擎参数顺序，不把候选值直接假定为任一引擎 API。

立绘窗口只是几何占位；最终人物脸部、双侧发型、武器/手部安全区需 P25/P26/P27 审定。本岗未绘制任何人物或怪物。

## 5. 透明、分辨率与命名

组件PNG全部为8位RGBA、sRGB、straight/unassociated alpha；源SVG不含业务文字。画布透明，部分组件内部底板不透明；“有alpha通道”不等于整张都是半透明。组件背景不得烘焙棋盘格。贴图不做自动trim、不旋转、不把阴影当碰撞边界。

文件模板：`placeholder_ui_<family>_<state>@1x.png` 与 `@2x.png`；SVG没有密度后缀。asset_id 是 `p24.ui.<family>.<state>`，密度是同一ID的variant；ID满足P22已读字符集，但尚未登记/受理。不得改写原卡牌、角色、enemy_id、phase_id或锚点身份。

当前未制作atlas，P30可在实测后采用4物理像素padding/2像素extrusion候选，必须重新检查过滤和透明边缘。建议先无损、clamp、bilinear、屏幕UI不开mipmap；这些是待受理建议，不是实际导入设置。字体导入格式也等P30确认。

## 6. 字体与中日排版

随包保留P23的Noto Sans SC、Noto Sans JP WOFF2原字节和DejaVu Sans TTF、许可原文。作者渲染用临时SFNT解码副本，未把转换字体当正式新发行字体。原文件名含400；实测OS/2.usWeightClass=400。内置family名为“Noto Sans SC Thin / Noto Sans JP Thin”，不能凭family名误判实际字重。字重与字体版本记录在font evidence中。

正文18、关键20、标题28、辅助16逻辑像素继承P23候选。日文run选择JP，中文run选择SC，符号用DejaVu回退。正式UI不得以PNG文字代替可重排文本。缺字显示明确U+XXXX提示并保留原UTF-8；不把“𠮷”改成“吉”。本包只证明展示夹具字形覆盖、静态边界与所检颜色对比，不证明所有日文塑形、ruby、辅助技术或玩家理解结果。

100/125/150/200%预览分别实际渲染为1280×856、1600×1070、1920×1284、2560×1712；它们是同一静态画板的像素密度变化。没有冒充真实系统DPI、200%文字重排或目标游戏测试。

## 7. 状态绑定与职责

`p23_asset_binding_candidates.json`按79个原widget/anchor条目记录视觉覆盖或保持原文字布局。它不实现任何数据绑定。业务字段、等待/未知操作、状态优先级保持P23；P14提交战斗结果，P19/P20绑定文字和当前值，P29控制演出；P24只给静态素材。

战斗“查询本次操作”不能被换皮改成新的只读命令或新command_id。学习连接可用不等于钱包入账。错误/禁用效果不能降低原因文字透明度；关闭动画后所有关键文字仍需由P19/P20保持可读。
