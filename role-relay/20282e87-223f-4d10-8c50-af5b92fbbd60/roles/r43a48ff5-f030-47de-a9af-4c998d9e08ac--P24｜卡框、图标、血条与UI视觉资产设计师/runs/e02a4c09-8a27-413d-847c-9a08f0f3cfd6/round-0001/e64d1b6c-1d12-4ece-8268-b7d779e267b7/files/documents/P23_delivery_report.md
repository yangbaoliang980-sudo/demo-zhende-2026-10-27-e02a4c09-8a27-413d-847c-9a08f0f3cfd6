- 出牌固定为选牌、选目标、明确确认；选择不提交；一次手势只允许一次原命令。确认按钮可用性继续来自 P19/P15/P14。
- 敌方卡面保留生命条、数字与护盾；下一次行动的行为、对象、基础值×次数与候选/未知标签常驻；实际掉血与吸收在结算日志独立展示。
- 生命、费用、手牌和结果由 P14 权威快照更新；关闭/跳过演出不控制结算和解锁。
- 学习连接、记录处理、钱包证明拆开。隔离不是作弊或惩罚；模拟 APPLIED、自报 production、收到 ACK 都不显示正式入账。
- 战斗未知按 P19 现有接口重发相同 ID/版本/载荷的原命令；它不是只读请求，且当前内存 pending 不支持完整重载恢复。
- 升级/领取未知时保留原身份并只查询；P21 的隔离 SQLite 能力已收到，P20 受理 gateway 仍缺，不能直接改 durable 标志接入。
- 三席草稿与保存顺序区分；恢复/迁移时显示实际保护原因；胜利、首通资格和奖励状态分别可读。
- 锚点按稳定实例 ID 展开；同页不同控件有独立固定 ID；当前 P19 的单位/卡牌 id 与 rect payload 保持。出牌卡不再存在时跳过飞行，不猜坐标。
