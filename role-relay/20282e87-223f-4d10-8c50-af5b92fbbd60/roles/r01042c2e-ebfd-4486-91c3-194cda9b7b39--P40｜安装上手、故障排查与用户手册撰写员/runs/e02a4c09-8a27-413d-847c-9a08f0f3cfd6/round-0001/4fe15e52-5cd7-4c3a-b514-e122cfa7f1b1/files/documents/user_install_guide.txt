B. 文件完整性核验（可复用的 Windows PowerShell 命令，不代表已取得 RC）
B01 将未来获得的正式安装文件放入你自选的单独目录。不要以管理员身份执行不明来源脚本。
B02 在 PowerShell 运行：
  $candidate = 'C:\\replace-with-your-verified-rc-file.exe'
  Get-FileHash -LiteralPath $candidate -Algorithm SHA256 | Format-List Path,Hash,Algorithm
  ※ $candidate 是示意用变量，不能照抄当做真实路径；实际扩展名由 P36 签发文件决定，不一定是 exe。
B03 将 Hash 与同一 RC 的 P36 签发清单精确逐字比较（大小写不影响十六进制值）。无文件或不一致：FAIL，隔离该文件并上报 P36；不得修改扩展名或重打包绕过校验。
