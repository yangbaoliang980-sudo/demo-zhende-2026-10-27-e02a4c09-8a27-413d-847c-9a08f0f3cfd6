# P23 减少动态效果与静音等价案例

版本：P23-MOTION-UX/0.1.0-proposal。IC-21 的阅读要求与 IC-23 的表现边界。P19 拥有最终界面状态和输入；P29 仅有装饰层。以下运行用例全部 NOT_RUN，需 P32 对固定游戏构建独测；本包仅完成对应静态设计。

## 模式语义

| 模式 | 可发生的表现 | 必须留下的信息 | 不得改变 |
| --- | --- | --- | --- |
| normal | 按 P29 受理方案飞行/撞击、轻量反馈；不承诺频率/时长 | P14 最终值、真实生命减少/护盾吸收、目标与结果文字 | 命令、随机序列、结算、输入资格 |
| fast | 缩短可选演出或直接跳到装饰终点 | 与 normal 同样的持久信息 | P14 的事件顺序和数值 |
| reduced | 无跨屏飞行、位移、抖动、闪白、滚动数字；静态选中/结果标记 | 静态终值和文字日志，不要求任何视觉运动 | 全部业务结果 |
| none | 可选动效、音效及触觉均关闭 | 与 reduced 同等信息，按正常阅读顺序 | 全部业务结果 |
| skip | 取消当前演出 epoch 的剩余装饰 | 已提交终值与日志；下次演出遵循选定模式 | 不撤销/重演领域命令 |

系统 reduce 偏好可作为首次默认；已明确选择的本次偏好不被下一条事件或重新聚焦覆盖。偏好落盘方式和 owner 需 P13/P21 接口受理，本轮不写存档字段。没有取得 OS 偏好时显示明确的“减少/关闭”选项，不捏造自动检测结果。切换模式立即停止不允许的运动，但不能清空结果记录或把输入置 READY。

## 不可被动画遮住的事实

“下一次行动”列出行动、目标、基础值×次数、确认程度。已经执行的事件另入“最近结算”。生命条直接对应当前 snapshot；漂浮数字是已提交事件的装饰副本，不能作为唯一信息。护盾吸收与 HP 减少不能混成一个“伤害”大字。

本包不规定具体闪烁 Hz，减少/关闭模式完全禁闪；普通模式也禁止全屏闪白与高对比连续闪烁候选。若未来 P29 使用闪烁，必须按目标显示和 WCAG 2.3.1 相关阈值另行验证，不能以“轻量”命名豁免。

## 用例与预期

| 案例 | 输入/动作 | 可读结果与领域不变量 | 执行方 / 任务 |
| --- | --- | --- | --- |
| RM-01 基础攻击 | 同一固定 P14 批次分别以四模式播放 | 终态 hash、命令数、HP/护盾/费用/手牌/outcome 全同；只有装饰不同 | P32 / UX-B09 |
| RM-02 护盾吸收 | hp_loss=0，absorbed>0 | 文字“生命减少 0；护盾吸收 N”；无需闪白判断命中 | P32/P33 / UX-A07 |
| RM-03 治疗/增益 | 实际提交的治疗或状态事件 | 最终数值与状态名称/层数可读，不依赖绿色或音效 | P32/P33 / UX-A07 |
| RM-04 出牌来源已移除 | P19 先绑定快照后手牌不再存在 | 没有有效来源 rect 就跳过飞行；仍显示真实日志。不能用原手牌 index 猜坐标 | P32 / UX-B10 |
| RM-05 目标死亡/失效 | 目标 anchor 无效或被裁掉 | 跳过对应装饰，不改目标、不复活、不影响终态 | P32 / UX-B10 / UX-B11 |
| RM-06 Boss 致死终局 | BATTLE_FINISHED 与最终 Boss 状态 | 先按 P14 终局显示；不自行演下一阶段或多发回合 | P32 / UX-B11 |
| RM-07 中途切 reduced | normal 正在演出时切换 | 当前 overlay 取消；最终数值保持；焦点留在模式选择；无补发命令 | P32/P33 / UX-B09 |
| RM-08 跳过/连续点击 | 同一 epoch 多次 skip | 取消幂等，旧动画完成回调不能改新界面；不改变输入资格 | P32 / UX-B09 |
| RM-09 序列缺口/旧批次 | event sequence gap / stale epoch | 不自造事件填空；请求/等待 owner 状态同步；不重放已提交业务 | P32 / UX-B09 |
| RM-10 resize/缩放/语言切换 | rect 变化 | P19 重新采样；旧rect失效；屏外目标跳装饰；焦点按稳定实例恢复 | P32/P34 / UX-B10 / UX-A02 |
| RM-11 断连/结果未知 | 提交后断连，关闭所有动效 | 常驻“待确认”；按 P19 同 ID/原载荷重发查证（非只读）；跳过不是恢复业务按钮 | P32 / UX-B07 |
| RM-12 无音频与颜色 | 静音、none、灰阶 | 玩家能读出敌方行动/目标/基础值与次数，找到出牌和结束回合，辨认生命与奖励状态 | P33/P39 / UX-B01 / UX-A07 |
| RM-13 恢复焦点/热插拔 | blur→focus，手柄断连→重连 | 0 个新增业务命令，不自动播放引导性强闪，恢复可见焦点 | P33/P34 / UX-B04 |

“终态 hash 相同”需要测试桩或记录器访问真实核心结果，本包的设计数据 SHA-256 不是这项测试。

## IC-23 锚点注意事项

当前 P19-PRESENTATION/0.1.0-proposal 传 `anchors.units[]` 与 `anchors.cards[]`，每项只含原 id 和 x/y/width/height。P23 的 `ux.*` 语义名不能替换 unit_id / card_instance_id 或偷加到封闭 DTO 中。坐标为 viewport 逻辑像素；DPR 转换仅在渲染边界做一次。

采样时机由 P19 控制。最终 snapshot 先绑定后，打出的卡牌可能没有当前 rect；按 RM-04 降级。若希望保留出牌前 origin 或接受布局版本，先由 P29/P19/P13 受理 P23-RFC-002 的版本化扩展。P23 不修改适配器。
