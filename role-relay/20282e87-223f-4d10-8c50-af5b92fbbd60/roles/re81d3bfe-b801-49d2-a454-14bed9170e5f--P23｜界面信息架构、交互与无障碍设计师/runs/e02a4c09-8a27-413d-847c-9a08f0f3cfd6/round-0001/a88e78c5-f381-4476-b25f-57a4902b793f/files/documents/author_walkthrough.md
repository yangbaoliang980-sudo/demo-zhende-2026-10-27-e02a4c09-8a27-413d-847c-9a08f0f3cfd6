# P23 作者线框走查与只读源码审阅

层级：AUTHOR_DESIGN_REVIEW。本文件不代替 P32 独测、P33 玩家试用、P35 独审。没有执行上游 P19/P20 游戏组件、真实 Anki 或目标引擎。

## 实际审阅材料与方法

实际解包读取附件及嵌套 ZIP，核对 relay manifest 与固定 Git blob；选取 56 个来源原件随包保留。读取了 P01 需求/范围、P02 状态/终局规则、P08 奖励/隔离原则、P13 路径/接口/环境、P19/P20 控制器和渲染器/样式、P21 对 P20 的恢复说明、P22 注册与缺失绑定、V6 接口/职责原文。来源哈希在 source_input_receipt.json。

上游 P19 战斗截图与用户提供的九张 P20 图是隔离实现的可见证据；未把截图当作真机或当前源码运行结果。已对 P23 的十八张 PNG 做联系图检查，并放大查看战斗、目标、学习隔离、未知升级、章节冻结、模态确认、排版和大字布局。SVG 文字/边界/命中尺寸及字体使用由本包作者工具另外记录。

逐态走查使用“动作 → 可见状态 → 焦点 → 唯一领域权限”的四列方法：选牌、选目标、确认、结束回合、请求未知、终局、草稿保存、升级取消、迁移冻结、学习隔离、奖励查证。只核对设计说明和图之间是否一致，没有将静态按钮当作执行过的交互。
