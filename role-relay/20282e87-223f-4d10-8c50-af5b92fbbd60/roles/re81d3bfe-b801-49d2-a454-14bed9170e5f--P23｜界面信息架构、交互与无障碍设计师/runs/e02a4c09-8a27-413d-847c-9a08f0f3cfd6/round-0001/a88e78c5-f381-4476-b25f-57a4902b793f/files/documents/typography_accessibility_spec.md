# P23 无障碍与中文／日文排版规范

版本：P23-A11Y/0.1.0-proposal。设计参考画布 1280×720 逻辑像素；不是 P01 已批准的目标分辨率。18 张 SVG 外加上下标注后为 1280×856；真实界面区域为 x=0, y=48, width=1280, height=720。正文规范不把 390px 上游截图当作移动端范围。

## 1. 信息必须有文字或形状对应

| 信息 | 必须保留的非颜色表达 | 不可作为唯一证据 |
| --- | --- | --- |
| 生命 | “生命 当前 / 最大”、血条长度；0 时“已倒下”按权威状态展示 | 红色、闪白、受击音效 |
| 护盾 | “护盾 N”，与生命分列；实际吸收写入结算记录 | 蓝色外圈 |
| 行动意图 | 敌人/技能、行为、目标、基础值×次数、候选/确认/未知标签 | 武器图标、箭头特效、音效 |
| 选中/焦点 | 明确选中文字/形状、连续外轮廓；焦点和选中分别表达 | 一种紫色或明暗变化 |
| 不可操作 | 持续原因；详情仍可到达；禁用形状 | 低透明度按钮 |
| 学习/奖励 | 连接、记录处理、钱包证明各自有中文标签 | 一个状态圆点或连接成功提示 |

美术替换不得把文字压进低对比人物图。必要时给文字独立底板；立绘安全区与卡面裁切由 P25/P24 定版。本包不输出切图、纹理或正式角色绘画。

## 2. 字号、行距和空间

| 文本用途 | 本岗候选下限 | 行距/处理 |
| --- | --- | --- |
| 页面标题 | 28 逻辑 px | 可换行，不遮挡状态区 |
| 区域标题 | 22 | 保持与正文层级 |
| 生命/费用/关键意图/错误下一步 | 20 | 禁止省略号和自动缩小 |
| 规则正文/按钮 | 18 | 正文约 1.55，日文约 1.6 |
| 非关键辅助信息 | 16 | 不承载唯一操作条件 |
| 注音 | 正文的约 0.6 | 为注音预留上方行高，不侵入上一行 |

44×44 是本岗候选命中区，3px 焦点轮廓和 3px offset 也是项目目标。它们不是 WCAG AA 的固定字号或统一命中尺寸要求。WCAG 2.2 的 2.5.8 AA 最小目标为 24×24 CSS px（带条件与例外）；本项目主动采用更宽松的触达目标。2.4.13 Focus Appearance 是 AAA，本包不将其冒充 AA 认证。

画布不足时重排、扩大文字区或允许局部纵向滚动，禁止把整页缩放为小字以挤入目标屏。W17 示意保留意图、费用和当前牌，其余手牌纵向到达；它不是实际 200% 放大运行结果。目标 OS / DPI / 全屏与窗口大小冻结后必须实测 100/125/150/200% 文字设置，记录可见逻辑视口、物理像素和截图。不能只在 1280×856 PNG 缩放查看后判定通过。

## 3. 截断、换行和长文本

关键意图、费用、生命、操作结果未知、禁用原因、奖励状态永不省略。允许辅助列表中的长名称占两行；仍不足时保留固定详情入口，详情显示原名全文且键盘/手柄可达。禁止仅靠 hover title。真实名称上线后按内容 ID 复测，不以设计夹具长度代表生产边界。

中文句读避免置于行首；前引号/前括号避免行尾。日文遵循禁则，闭括号、句读与适用小假名/长音的处理由实际排版引擎和 locale 决定；不得用逐字插空格“修复”日文。数值与单位、乘号次数、HP 分数尽量不拆开，溢出时整组到下一行或使用详情，不把 12×2 改成 24 的推算伤害。

以扩展字素簇处理光标、截断和删除。组合假名、代理对、变体序列不能从中切开。ruby 基字与读音一起测量，资源不支持 ruby 时用括号读音并增加行高。`typography_test_strings.json` 的 12 项包含中日长名、句读、混排、注音、组合字符、长错误、长 ID 和数值边界。

UTF-8 原文用于展示层时可以选择字体和软换行；不改 Anki 原始字段、事件签名、内容 ID 或哈希。显示层标准化不能回写为业务身份。技术 ID 只在可展开的详情中换行，并保持可复制原字节。

## 4. 字体与缺字

设计预览使用已附 Noto Sans SC / Noto Sans JP WOFF2，按 `lang=zh-Hans` 或 `lang=ja` 选择优先字体并跨族回退；箭头及数学符号采用随包 DejaVu Sans 原字节回退；不把“有一个通用 CJK 字体”当作全部日文/中文都齐字。许可原文和字体来源在 fonts/ 与 font_provenance.json。正式风格和发行许可审核仍分别交 P25/P37。

字体装载失败或源字缺失时：首先回退到已许可且覆盖目标字符的字体；仍缺字则显示可见的 `[缺字 U+XXXX]` 占位并提供原文详情。不得悄悄把“𠮷”改为“吉”、删去字符或改变底层内容。字体仍在加载时关键状态采用稳定宽度/备用字体，加载完成重算锚点并保留焦点。

测试夹具刻意包含 U+20BB7 与 U+F0000；这两个字形不包含在本包三份字体中，W16 明示替代文本。原始 UTF-8 测试字串保留。字形 cmap 检查只证明当前字体覆盖集合，不证明组合塑形、读音、字体美术质量或屏幕阅读器结果。日文文案为候选，P33 双语审阅 NOT_RUN。

## 5. 对比与非颜色冗余

普通文字按 4.5:1 候选基线检查，关键轮廓/状态边界按 3:1 检查。算法基于 sRGB 相对亮度；`accessibility_tokens.json` 指定六对实色前景/背景，作者结果保存到 evidence/author_validation。它只覆盖低保真 token，不能替 P25 正式色板、透明层、渐变或立绘背景自动背书。

禁用控件虽可能落在 WCAG 的例外中，本项目的原因文字仍要求可读对比。使用灰阶、关闭声音、关闭动画再执行 UX-A07 / UX-B01；仅“有文字”还不等于玩家能迅速理解，需 P33 记录正确率和时间。

## 6. 焦点、命中与辅助技术

采用逻辑阅读顺序，不使用 positive tabindex 把视觉顺序和键盘顺序拆开。标题/异常状态可程序聚焦，重复刷新不抢焦点。焦点轮廓不能被 fixed 底栏、toast 或遮罩完全遮住。模态升级框打开后背景不可交互；关闭返回原触发点。行内回合复核不是模态，不制造键盘陷阱。

大小是命中区域而不是图标笔画；图标可较小，但点击矩形至少候选 44×44。相邻目标保留清晰间隙；密集手牌不以重叠卡尖作为唯一点击区域。鼠标、键盘、手柄能力见 keyboard_focus_matrix.tsv。

无障碍树要求角色/名称/状态明确，selected 与 focused 独立，disabled 有可读原因，进度值有最大/当前数；装饰头像、漂浮伤害重复副本不被重复朗读。实际桌面引擎桥接尚未验证。无音频可完成核心操作；音效与震动都不是必需通道。

## 7. 可度量验收与引用

验收任务见 ux_acceptance_tasks.tsv：关键四项意图识别、一次手势一次命令、44px 命中、对比算法、200% 重排、CJK 缺字、焦点遮挡、真实辅助设备分别记录。作者 SVG 截图与静态检查不替代这些真机/用户任务。
